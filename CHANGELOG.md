# Changelog

## 0.1.0 — 2026-07-24

- Added official COVIT launch and persistent browser integration.
- Added sidecar-only and save-and-embed workflows.
- Added Swinsian, Finder, clipboard, automatic-context, Raycast, and Ghostty entry points.
- Added a Textual terminal interface and diagnostic log viewer.
- Added an importable Keyboard Maestro macro group.
- Added optional COV search-query overrides.
- Added a native album-folder chooser for save-only and save-and-embed workflows.
- Added repository, licensing-boundary, integration, testing, and troubleshooting documentation.
